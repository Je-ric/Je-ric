## Projects

My current work at **CLSU** focuses on **CSMS**, a course syllabus management system for creating and managing academic syllabi.

Outside work, I build tools and projects around practical needs and personal interests:

- **DFD Studio (Flowdesk)** — A browser-based editor for creating and exporting data flow diagrams.
- **Office Task Tracker** — A tool for organizing and tracking office tasks.
- **TRGC** — A church attendance system and website for The Risen Generation Church.
- **StyleGen & ToolGrid** — Visual CSS generators and browser-based utilities.
- **GameZone** — A collection of interactive browser games.
